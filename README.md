# Scientific Calculator

A responsive and interactive **Scientific Calculator** built using **HTML5, CSS3, and JavaScript**. The project provides basic arithmetic operations along with scientific functions, memory operations, degree mode, and a clean user-friendly interface.

## Overview

The Scientific Calculator is a browser-based calculator designed to perform both basic and scientific mathematical calculations.

It includes a simple and intuitive interface with dedicated buttons for arithmetic operations, scientific functions, memory operations, and calculation controls.

## Features

### Basic Arithmetic Operations

- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Decimal calculations
- Equals (=)

### Scientific Functions

- Sine (sin)
- Cosine (cos)
- Tangent (tan)
- Logarithm (log)

### Memory Functions

- **MC** – Memory Clear
- **MR** – Memory Recall
- **M+** – Add value to memory
- **M-** – Subtract value from memory

### Additional Features

- AC – Clear all input
- DEL – Delete the last entered character
- Degree mode for trigonometric calculations
- Light mode interface
- Scrollable calculator display
- Responsive user interface
- Clean and modern calculator layout
- Real-time calculation handling using JavaScript

## Technologies Used

- **HTML5** – Structure of the calculator
- **CSS3** – Styling, layout, and responsive design
- **JavaScript (ES6)** – Calculator functionality and logic
- **JavaScript Math API** – Mathematical and scientific calculations

## How to Run the Project

### Method 1: Run Directly

1. Download or clone the repository.
2. Open the project folder.
3. Double-click `index.html`.
4. The calculator will open in your browser.

### Method 2: Clone Using Git

```bash
git clone https://github.com/samgupta221/Scientific_Calculator.git
```

Navigate to the project:

```bash
cd Scientific_Calculator
```

Open `index.html` in your browser.

No external libraries or package installation are required.

## Usage

### Basic Calculations

Example:

```text
10 + 5 = 15
20 - 8 = 12
6 × 7 = 42
50 ÷ 5 = 10
```

### Scientific Calculations

The calculator supports trigonometric and logarithmic operations.

Examples:

```text
sin(90°) = 1
cos(0°) = 1
tan(45°) = 1
log(100) = 2
```

### Degree Mode

The **Degrees** checkbox can be enabled when performing trigonometric calculations in degrees.

For example:

```text
sin(90°) = 1
cos(60°) = 0.5
tan(45°) = 1
```

## Memory Operations

The calculator includes four memory functions:

| Button | Description |
|--------|-------------|
| MC | Clears the stored memory |
| MR | Recalls the stored memory value |
| M+ | Adds the current value to memory |
| M- | Subtracts the current value from memory |

## Control Buttons

| Button | Description |
|--------|-------------|
| AC | Clears the complete calculation |
| DEL | Deletes the last entered value |
| = | Calculates the final result |
| . | Adds a decimal point |
